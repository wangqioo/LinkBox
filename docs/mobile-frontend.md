# Mobile Frontend

LinkBox now contains the mobile frontend in `mobile/`.

## Run

Start the backend first:

```bat
cd C:\Users\100448405\LinkBox\server
C:\tmp\node-v22.22.3-win-x64\node.exe index.js
```

Start the mobile UI:

```bat
cd C:\Users\100448405\LinkBox\mobile
npm.cmd run dev
```

Open:

```text
http://localhost:5173
```

Desktop web remains in `client/`; mobile-only WeChat-style UI lives in `mobile/`.
